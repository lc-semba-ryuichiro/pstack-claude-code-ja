# PR Review Canvas

プルリクエストの差分（diff）をファイルツリー順ではなく、レビュアーの理解しやすさを重視した構成のインタラクティブな Cursor Canvas としてレンダリングする Cursor プラグインです。

## 含まれる機能

- `pr-review-canvas`: PR の差分を「最上部にコアロジック」「中盤に結線・統合処理（要約）」「最下部にボイラープレート（概要）」の順で表示する Canvas を構築します。また、特に複雑な箇所には擬似コード、実行トレースの例、インラインのコールアウト（注釈）を追加します。

## 使用するタイミング

- プルリクエストをレビューする際、単なるファイル単位の差分ではなく、本質的なリスクを浮き彫りにするウォークスルーが欲しいとき。
- 積み上がった一連の PR（PR スタック）を、人間のレビュアー向けに要約するとき。
- 差分のウォークスルー、変更セットの概要、あるいは「実質的にどこが変わったのか」を把握したいとき。

「PR review canvas」「review this PR on a canvas」「walk me through this diff on a canvas」などのフレーズを入力するか、エージェントに PR の URL やブランチの参照（ref）を指定してトリガーします。

## 構成の仕組み

このスキルは、レビュアーにとっての重要度に基づいて変更をグループ化します。

1. **コアロジック（Core logic）** — 新しい挙動、アルゴリズムの変更、状態遷移、API サーフェスの変更。コンテキストを含めた完全な差分を表示します。
2. **結線と統合（Wiring & integration）** — ルーティングの登録、DI（依存性の注入）、設定のつなぎ込み。要点を凝縮して表示します。
3. **ボイラープレートと機械的な変更（Boilerplate & mechanical）** — インポート文、リネーム、自動生成コード、フォーマット調整。リスト形式で要約し、直接関連がない限りインライン差分は表示しません。

さらに、高密度なロジックに対する擬似コード、差分だけでは挙動の変化を予測しづらい箇所に対する具体的な変更前後の実行トレース例、そして特に注意すべき箇所やリスクの高い変更ブロック（hunk）に対するインラインコールアウト（`Subtle`、`Breaking`、`Race condition`、`Perf`）を重ねて表示します。

## 要件

- Canvas 機能が有効になっている Cursor
- 差分ソースへのアクセス環境：ローカルのブランチ／参照（`git diff`）、GitHub の PR URL または番号（`gh pr diff`）、あるいは Graphite スタック（`gt` CLI / `gh`）
