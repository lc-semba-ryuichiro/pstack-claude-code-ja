# pstack harness tree

このフォルダは、`pstack/skills`、`pstack/agents`、`pstack/docs/guide`、`pstack/README.md`、`pstack/LICENSE`、および `pstack/plugin.json` から自動生成されています。手動で編集しないでください。

Claude Code は `claude-code/` をインストールします。このツリーでは、`pstack/automations` や `pstack/assets` など、`pstack/` 内のその他のディレクトリは除外されています。ツリーから除外された pstack 内のファイルへの相対リンクは、代わりに GitHub の `main` ブランチ上の該当ファイルを指すようになっています。

上記のソースファイルを編集した後は、リポジトリのルートディレクトリから `node scripts/generate-pstack-harness-trees.mjs` を実行し、生成された結果をコミットしてください。
