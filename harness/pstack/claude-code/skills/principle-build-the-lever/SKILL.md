# Build the Lever

作業が自明でない場合、手作業で行うのではなく、それを実行するツール（codemod、スクリプト、ジェネレーター、または再実行可能なチェック）を構築すること。基準は繰り返しの有無ではなく、自明かどうかです。ツールを省略してよいのは、ごく少数の明らかな編集のみです。

- 最初の1単位は手作業で行い、その後ツールを構築し、その単位で再実行して証明します。安全に再実行できるようにします。
- 決定論的なツールはファンアウト（fan-out）に勝ります。ファンアウトを行う場合は、レシピ、検証コントラクト、および境界（fences）を、委譲先が読み取り専用で参照する1つのスキルとして記述します。
- この原則を適用するとファイルが生成されます。diff にスクリプト、codemod、ジェネレーター、または委譲先スキルが含まれていない場合、それは適用しなかったことを意味します。作業の寿命がセッションを超える場合はコミットします。
- 作業を実行または証明する最小のスクリプトを構築すること。決してフレームワークを作らないこと。
