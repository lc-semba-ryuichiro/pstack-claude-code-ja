# Guard the Context Window

**なぜ（Why）:** コンテキストのオーバーフローは推論の品質を低下させ、圧縮によるアーティファクトを生み出し、進行を停止させるからです。

**パターン:**
- **フェーズのサイズを測り、スコープの上限を設ける:** フェーズごとのファイル数を制限し、ターンごとの予算を設定し、メカニズムのコストを考慮します。
