# Encode Lessons in Structure

教訓に判断が必要でエンコードできない場合は、指示をより目立たせ、失敗モードの例を追加します。

**系（Corollary）:** 修正が構造的なものである場合、構造的な修正のみを使用します。指示は単なる症状にすぎません。
